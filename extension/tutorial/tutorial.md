# Tutorial

Tulis tutorial di file ini. Tampilannya muncul di dialog tombol Info.

## Menulis gambar

Taruh file gambar di `extension/tutorial/images/`, lalu tulis satu baris sendiri seperti ini:

@gambar(agent-off.jpg)

Saat build, gambar itu ditanam ke dalam tutorial. Format yang didukung: png, jpg, gif, webp.

## Format lain

- **Tebal** dan `kode` di dalam kalimat
- Daftar berbutir dan bernomor
- Judul dengan `#`, `##`, `###`
